# رحلة فارس 🧭

لعبة مغامرات تعليمية للأطفال (٥–١٠ سنين). فارس وإخواته فريد وفرحة بيمشوا على كورنيش إسكندرية لحد مكتبة الإسكندرية، وهناك بوابة سحرية بتوديهم جزر العلم. معاهم «نوري»، نور فنار إسكندرية القديم. كل جزيرة بتنوّر دور من الفنار.

- **تتسطب** على الآيباد والآيفون والأندرويد: افتح اللينك من Safari أو Chrome ← مشاركة ← «إضافة إلى الشاشة الرئيسية». بتشتغل من غير نت بعد أول مرة.
- **مفيش إعلانات ولا شراء** جوه اللعبة، ومفيش أي بيانات بتخرج من الجهاز.
- **ركن الأهل** (⚙️ وعليه سؤال حساب): الأصوات، وصوت الراوي، وحد اللعب اليومي.

## المحتوى دلوقتي
1. إسكندرية: الكورنيش، كوبري ستانلي، قلعة قايتباي، الترام، المدرسة، مكتبة الإسكندرية والبوابة.
2. 🌱 جزيرة النبات: ازرع البذرة (بالترتيب)، النبتة محتاجة إيه (فرز)، قطف التفاح بالعدد (عدّ لحد ٥).
3. نور أول دور في الفنار.

قريب: 💧 جزيرة المية، 🔦 كهف الشجاعة، صوت الراوي بصوت بابا، ورسومات أفخم.

الكود: Phaser 3 (MIT، في `vendor/`) + خط Cairo (OFL). كل الرسومات SVG أصلية مرسومة بالكود.
